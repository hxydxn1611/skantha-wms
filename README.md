# Skantha WMS & W.A.R.L.O.G. AI Vision

Enterprise Warehouse Management System with Autonomous Computer Vision, Powered by **Ultralytics YOLO11**, ByteTrack Multi-Object Tracking, Database-Driven Tripwires, Gate ANPR, and Multi-Camera Orchestration.

## Key Features
- **Authoritative Perception Pipeline**: Single-pass YOLO11 inference with zero redundant model loops.
- **Multi-Device & Mobile Web Support**: Full browser camera streaming (`navigator.mediaDevices.getUserMedia`).
- **Enterprise WMS Ledger**: Authoritative bin inventory, gate passes, and cycle count auditing.
- **Production Server**: Multi-threaded Waitress WSGI server (`python run_production.py`).
